# Afroswiden Real Estate Management System

A modern, full-featured **Real Estate Management System** developed for the Ethiopian market.

---

## 📋 Project Overview

**Afroswiden Real Estate Management System** is a comprehensive web-based platform that facilitates property listing, searching, reservation, payment, and management.

This project was developed as a **Senior Year Capstone Project** in collaboration with **Afro-Sweden Real Estate**, a real company based in Addis Ababa, Ethiopia. The system was designed specifically with their actual business requirements and operational workflows in mind.

> **Important Note**:  
> Afro-Sweden Real Estate is a legitimate company located in Addis Ababa. You are welcome to explore, study, learn from, and fork this project for **educational purposes**. However, please **do not use the company’s real name, logo, contact information, or branding** for any commercial or public deployment without explicit permission.

---

## ✨ Key Features

### **Public Platform**
- Elegant and responsive dark-themed design
- Advanced property search (type, location, keywords)
- Detailed property listings with images
- Customer testimonials and reviews
- Contact form with email notification

### **User Dashboard**
- Secure registration and login
- Profile management with avatar upload
- Submit property reviews

### **Admin & Agent Panels**
- Full CRUD operations for properties and users
- Activity logging and audit trail
- Comprehensive reporting system (Users, Properties, Payments, Demand, etc.)

### **Payment Integration**
- **Chapa Payment Gateway** integration (Ethiopian payment solution)

---

## 🛠️ Technology Stack

- **Backend**: PHP 8+
- **Database**: MySQL / MariaDB
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Payment**: Chapa API
- **Email**: PHPMailer
- **Design**: Custom responsive UI
